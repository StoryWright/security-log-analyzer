# Development

Run `node --test` and the demo command in the README before proposing a change. Add a behavioral test when changing detection or workflow behavior. Keep fixture events synthetic and identify their provenance. Preserve the distinction between local unit tests, scenario evaluation, and live system validation.

Use the existing formatting when editing a file. The programs use Node built-in modules and require no dependency installation. Inspect the Actions tab for hosted checks and keep live integration validation separate from unit tests.
